GRASSROOTS ENGINE MANAGEMENT · FREEDOM FC-03 FIRST

Unsupported is not obsolete.

Many good standalone ECUs sit unused because their software stopped years ago. AhhPuck gives them modern logging and safe, step-by-step tuning. We start with the Freedom FC-03 on a 4A-GE 20V. The same process will then work for other ECUs.

  • Better logging · more than the original software ever gave
  • Safer tuning · one small, reversible step at a time

HOW IT WORKS

One loop, from plug-in to a proven improvement.

The app, the workbench and the command-line tools all follow this loop. Every step leaves a file on disk, so nothing is lost.

1ConnectUSB, serial, bridge or replay
2Identifywhich ECU, which firmware, which channels
3Profile & limitsengine, sensors, goal, hard limits
4Baselinesaved, hashed, repeated
5Proposeone small change
6Approvea person checks and says yes
7Testa controlled run with stop rules
8Assessdid it help, and did it repeat?
9 · LEARNwrite it to the ledger. The next step is smaller, or the loop stops.
Monitor mode is steps 1 to 4. It is the first release that can go in a car.
Engineer mode adds 5 and 8 as reports. Nothing is sent to the ECU.
Optimize mode closes the loop, fuel only, behind every safety gate.

SAFETY LIMITS

Limits are set before the engine starts.

These values come from the safety policy file the tools enforce. They are provisional and must be checked for your engine, but they are never invented on the spot.

  • never learn from a run with a protection fault
  • never change fuel and ignition in the same experiment
  • never guess unknown cells without a review flag
  • never let an AI authorize an ECU write
  • always keep the source map, the diff and a rollback copy
HARD LIMITSpolicy 0.1-provisional
  • Max fuel change per cell2.0 %
  • Max ignition change per cell1.0 °
  • Max RPM7 800
  • Max coolant105 °C
  • Max intake air temp65 °C
  • Min battery voltage12.0 V
  • Max knock level0.15
  • Min oil pressure under load180 kPa
REQUIRED EVIDENCE
  • original map backed up
  • engine profile checked
  • injector data checked
  • fuel pressure checked
  • wideband calibrated
  • ignition offset checked
  • sensors plausible
  • logs repeatable

LEARNING FROM EVIDENCE

An improvement only counts when it repeats.

Each round compares a baseline, a candidate and a repeat of the candidate. The result goes into a ledger that only grows. A run with a fault is never reused.

Quality gate

target 96 %
  • Objective score
  • Safety-pass fraction
  • Map coverage
  • Repeatability
  • Sensor confidence

Missing evidence counts as zero. A few good dyno pulls, or an AI opinion, can never reach the target alone.

Learning ledger

append-only
  1. #01baseline capturedclean
  2. #02fuel 11×7 −1.5 %improved · repeated
  3. #03fuel 11×8 −1.5 %not repeatable
  4. #04fuel 11×8 −0.8 %improved · repeated
  5. #05knock in runaborted · not reused

If a step does not repeat, the next one is smaller. If protection fires, nothing is learned from that run.

Defined

  • Tuning workflowbaseline, proposal, controlled run, assessment, rollback

In progress

THE BIGGER GOAL

One process. Many unsupported ECUs.

The Freedom FC-03 is the proving ground. Once the loop is proven on a real car, the same parts become adapters for other good ECUs that lost their software, not their value.

Freedom FC-03MoTeC M4 / M48 / M800Autronic SM2 / SM4Emerald K3 / K6Haltech PlatinumAEM Infinity / Series 2Link G1 – G4+DTA S-seriesVEMS V3MegaSquirt MS2 / MS3rusEFI / Speeduino
Shared core
  • Transport adapter
  • Frame decoder
  • Live safety monitor
  • Session recorder
  • Optimizer gate
  • Learning ledger
Lower costA second-hand ECU and a serial cable, instead of a new ECU, harness and licence.
Better loggingModern sample rates, phone sensors, hashes and exports the old software never had.
Safer tuningEvidence-based, repeatable, reversible. The same loop, whatever the box says on the lid.
Sky is the limitEvery adapter starts read-only. Writing needs its own proof, every time.

Candidate ECUs are listed in the repository. None starts development until the FC-03 trial passes its gates.

RELEASE GATES · FC-03 TRIAL

Nine gates before a single write.

Each gate must pass before the next is considered. A working dashboard is never proof of a safe tune.

  1. 1Replay and simulated data
  2. 2USB detection without ECU commands
  3. 3Read-only ECU identity
  4. 4Read-only live monitor and logging
  5. 5Fault tests: disconnect, stale data, bad sensors, power loss
  6. 6Car check at idle and light load
  7. 7Load testing with independent instruments
  8. 8Human-reviewed proposals
  9. 9Only then, one restricted write experiment
