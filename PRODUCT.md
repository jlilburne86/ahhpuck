# AhhPuck Product Context

AhhPuck is a calm, evidence-first, local read-only diagnostic workbench for Freedom ECU users, starting with Toyota AE86 20V and 16V engines. It helps mechanics, calibrators, reviewers, and learners understand what is known, what is missing, and what must remain protected before incremental tuning work proceeds.

The current milestone is the restored Freedom adaptation boundary: preserved exports and logs, exact firmware/channel contracts, deterministic diagnostics, and AI-ranked next measurements. It does not claim live ECU access, map editing, or write capability. Unsupported is not obsolete; an unsupported signal stays visible as an evidence gap rather than becoming a guess. The downloaded rusEFI BMW record is a parser/reference fixture, not the product target.

The native iPhone/iPad experience has two modes: glance mode for a quick in-car/replay read and review mode for flow state, evidence gaps, findings, and reportable context. Japanese and English use the same information architecture and the same source data.

Voice: precise, calm, technical, non-alarmist. Accessibility target: WCAG 2.2 AA, VoiceOver labels, Dynamic Type, reduced motion, and high-contrast state colors.
